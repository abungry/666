PART 1 · 理论推导

证明：卡诺循环的热温商之和等于零

采用物理化学符号约定 ΔU = Q + W（W 为环境对体系做功，W = −∫p dV）。工作物质为 n mol 理想气体，热容比 γ = Cp,m/CV,m。

0循环的四个过程

过程名称约束条件体积温度
1→2等温膨胀与高温热源 Th 接触V₁→V₂Tₕ 不变
2→3绝热膨胀无热交换 Q=0V₂→V₃Tₕ→Tc
3→4等温压缩与低温热源 Tc 接触V₃→V₄Tc 不变
4→1绝热压缩无热交换 Q=0V₄→V₁Tc→Tₕ

①等温过程的热量

理想气体内能只是温度的函数，等温过程 ΔU = 0，故 Q = −W = ∫p dV = nRT·ln(Vf/Vi)：

Qh = nRTh ln(V₂/V₁) > 0
Qc = nRTc ln(V₄/V₃) < 0

高温等温膨胀吸热 Qh；低温等温压缩放热 |Qc|。

②绝热过程无热温商贡献

2→3 与 4→1 均为绝热过程：

Q2→3 = Q4→1 = 0

因此它们对热温商之和 没有贡献，只需考察两个等温过程。但绝热过程提供了关键的体积比关系（见第③步）。

③用绝热过程方程建立体积比关系

理想气体可逆绝热过程满足 TVγ−1 = 常数。分别应用于两条绝热线：

ThV₂γ−1 = TcV₃γ−1　(i)　　TcV₄γ−1 = ThV₁γ−1　(ii)

(i) ÷ (ii)，温度因子恰好消去：

V₂/V₁ = V₃/V₄　⟺　V₄/V₃ = V₁/V₂

④热温商求和

Qh/Th + Qc/Tc = nR·ln(V₂/V₁) + nR·ln(V₄/V₃) = nR·ln(V₂V₄ / V₁V₃)

代入第③步结论 V₂/V₁ = V₃/V₄，得 V₂V₄/(V₁V₃) = 1，而 ln 1 = 0：

Qh/Th + Qc/Tc = 0
证毕 ∎　卡诺循环的热温商之和等于零。这一结果与工作物质无关（此处以理想气体显式验证），它正是定义热力学温标与熵（∮ dQ可逆/T = 0）的出发点。
推论 —— 卡诺热机效率：循环净功 −W净 = Qh + Qc，故 η = (Qh + Qc)/Qh = 1 + Qc/Qh = 1 − Tc/Th，只取决于两个热源的温度。

PART 4 · AI 使用说明

AI 工具使用情况

使用工具

Trae CN IDE（内置 Kimi-K3 大模型），在本地单文件 HTML 中完成全部推导整理与动画代码编写，零外部依赖，浏览器直接打开即可运行。

主要提示词（首轮）

"根据理想气体卡诺循环四个过程（等温膨胀、绝热膨胀、等温压缩、绝热压缩），推导并证明热温商之和 Qh/Th + Qc/Tc = 0，写出主要步骤；并制作单文件 HTML 动态演示：动态 p–V 图 + 活塞运动与热量传递动画，标注 T、p、V、Q、W，提供播放/暂停等控制。"

多轮修改交互

① 初版生成后，要求四个过程用不同颜色区分并在 p–V 图上加方向箭头与状态点 1–4 标注；
② 追加活塞–气缸同步动画：分子运动速率随 √T 变化、颜色随温度红蓝渐变，等温过程显示热源与热量箭头，绝热过程显示保温层；
③ 增加单步、速度调节、参数滑块（Th、Tc、膨胀比）以便课堂演示；
④ 增加数值验证表实时核对 ΔU = Q + W 与热温商之和；
⑤ 要求 AI 自查科学准确性：符号约定 ΔU = Q + W、绝热方程 TVγ−1 = 常数、η 两种算法一致性，均通过数值验证（见 Part 3）。

准确性核查方式

拖动任意参数滑块，验证表中热温商之和恒为 0、ΣΔU 恒为 0、效率两种算法始终相等——推导结论在任意参数下成立，而非特例巧合。
