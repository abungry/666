# Spatial AI Companion

融合 GIS、用户偏好、关键词记忆库与 DeepSeek 的个性化旅行推荐网站。

## 运行

1. 复制 `.env.example` 为 `.env`，填入 `DEEPSEEK_API_KEY`。
2. 确认本机已安装 Node.js 20 或更高版本。
3. 在项目目录运行：

   ```bash
   npm start
   ```

4. 浏览器打开 `http://127.0.0.1:3000`。

不要直接双击 HTML 体验 DeepSeek 功能；前端需要通过本地服务安全调用 API。未配置密钥时，聊天会自动降级为原有的本地空间推荐。

## 新增能力

- 按用户 ID 隔离的关键词记忆库，只保存搜索关键词，不保存完整搜索句。
- 记忆关键词可添加、重命名、删除，并设置高/中/低优先级。
- “直接推荐”会优先按记忆优先级、使用次数和最近使用时间生成结果。
- 记忆支持“喜欢/避开”方向、优先级、使用次数和推荐反馈学习。
- 普通对话先由 DeepSeek 解析同行人、时长、体力、预算等约束，再检索 OpenStreetMap 候选地点，并用高质量模型结合记忆、收藏、距离进行精排和解释。
- DeepSeek 密钥仅由服务端环境变量读取，不会写进浏览器代码或本地存储。
