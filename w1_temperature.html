温度是怎样"诞生"的？

假设人类还没有"温度"这个词。仅凭"热平衡"现象与热力学第零定律，

STEP 01

在说出"温度"之前，先定义"热平衡"

题目最重要的规则：不得先用"温度相等"定义热平衡。 我们必须只使用能直接观测、能动手操作的东西。

器材两种壁

绝热壁：两侧系统的宏观状态互不影响（近似：保温杯壁、厚泡沫）。

透热壁：允许"热相互作用"通过（金属壁）。注意——我们只规定壁的材料与操作，不规定它"传什么"。

操作热平衡的操作定义

两个各自处于内部平衡的系统 A、B，用刚性透热壁接触； 持续观测任意宏观可测量（压强、液柱高度、电阻、颜色……）。

若经过足够长时间后，所有读数都不再随时间变化，就称 A、B 的这一对状态互为热平衡，记作 a ~ b。

整个定义中只出现三样东西：壁、接触、读数是否变化。 没有"温度"，没有"冷热"，也没有"热量"——它们一个都还没出生。

STEP 02

第零定律的逻辑结构：它到底断言了什么？

把热平衡看成定义在"所有系统的所有状态"集合上的一个关系 ~。 数学上，只有等价关系才能把集合划分为类。等价关系需要三条性质——逐条用实验"审讯"：

i对称性 a~b ⇒ b~a

点击按钮，按实验顺序检验。
✓ 成立。"接触"是相互的：A 对 B 读数无影响，B 对 A 自然也无影响。对称性直接蕴含在操作定义中。

ii自反性 a~a？

这是三条性质中最微妙的一条，先别急着回答。
⚠ 不是经验结论，而是数学约定。 第零定律的表述只涉及三个可区分系统，无法令 B=C=A 推出 a~a；"自己接触自己"在实验上也无意义。 为了使用"等价关系"这一数学工具，我们把 a~a 作为平凡约定显式补入——它不增加任何物理内容。

iii传递性 a~b, b~c ⇒ a~c

测出 a~b、b~c 之后，a 与 c 一定热平衡吗？这只能去问自然。
✓ 实验说：成立。这就是热力学第零定律本身（Fowler, 1931 命名）。 它是由实验归纳出的经验定律，不是逻辑必然——完全可以设想 a~b、b~c 却 a≁c 的世界，只是我们的宇宙不是这样。
📌 小结逻辑结构：对称性来自操作定义；自反性是补入的约定； 传递性是唯一需要实验支持、也唯一被称作"第零定律"的内容。三性齐备，"热平衡"才是一个等价关系。
STEP 03

等价类：把"互相平衡的状态"关进同一个格子

等价关系在数学上保证：全体状态被无遗漏、不重叠地切成若干个等价类 [a] = { x : x ~ a }。下面这个动画，就是温度"出生"的瞬间——

🕸 九张"状态卡"的归类实验

A、B、C 三个系统各取 3 个状态。逐对做热平衡实验，再用第零定律推断，看看会发生什么。

每次重新生成，平衡关系都是随机的，但结论永远相同。
✨ 温度，在此诞生。给每个等价类任意贴上一个互不相同的数值标签 θ， 并定义状态 x 的"温度"就是它所在类的标签：
a ~ b　⟺　θ(a) = θ(b)
这句话既是温度的定义，也是第零定律保证其自洽的定理：正因为有传递性， "我和 B 同标签、B 和 C 同标签 ⇒ 我和 C 也同标签"才不会打架。 温度首先不是一把"尺子"，而只是等价类的名字。
🔬 更严格的版本（Carathéodory / Born）： 两个系统的平衡态由各自的状态变量刻画（如 (pA,VA)、(pB,VB)）， 热平衡表现为一个方程 FAB=0。第零定律（传递性）保证这些彼此独立的方程是相容的， 数学上可推出每个系统都存在一个态函数 θ，使平衡条件化为 θA = θB。 温度的存在性是一个定理，温度的具体形式则不是。
STEP 04

第零定律能唯一确定温度函数吗？不能。

标签只要能区分类就行。把所有标签重新起一遍名字，相等结构毫发无伤。 亲手换几个函数 θ′ = f(θ) 看看：

条件 1保住"相等"：f 为一一对应

若 f 不是单射（如 1+sin θ），两个不同的类会被贴成同一个标签—— 出现"θ 不同却 θ′ 相同"，温度判据直接崩溃。数学条件：f 必须是双射（一一对应）。

条件 2保住"冷热"：f 严格单调递增

但"谁更热"的次序并不来自第零定律（等价类之间天然没有大小！），它来自另一条经验： 热接触后热流的方向。一旦约定"θ 越大越热"，重标号就必须严格单调递增（连续温标还要求连续）。

🧊 所以第零定律给了我们什么？只给了标签的存在与相等判据； 没给零点、没给单位、没给等距间隔、没给绝对零度。θ 与 θ²、摄氏度与华氏度，在第零定律面前完全平等。
STEP 05

拆穿一个循环论证

待审查的原话：「温度相等所以热平衡；热平衡所以温度相等；因此第零定律证明了温度的存在。」 点击按钮逐句审讯，再看正确的逻辑链：

句①「温度相等所以热平衡」——"温度"在此处是一个尚未定义的词。用未定义概念去定义热平衡，是无效前提。
句②「热平衡所以温度相等」——若温度还没出生，"相等"无从谈起；这句话将来能成立，但它是温度定义的重言式，不是新发现。
结论③ 第零定律没有"证明温度客观存在"。它只提供传递性；温度是我们在等价类上主动构造的标签函数——存在性靠构造，自洽性靠第零定律。
🔗 三句话首尾互证，构成一个封闭的环——这正是"循环论证"名字的由来。
1
操作先行：用透热壁 + "读数是否变化"定义热平衡 a~b，全程不出现"温度"。
2
经验定律：实验归纳出传递性（第零定律），对称性由定义给出，自反性作为约定补入。
3
数学结论：等价关系把全体状态划分为互不相交的等价类。
4
定义温度：给每个类贴标签 θ，规定 a~b ⟺ θ(a)=θ(b)。
5
于是「热平衡 ⟺ 温度相等」是定义的直接推论；第零定律保证这个定义处处自洽、永不打架。链条是线性的，不再回环。
STEP 06

从经验标签 θ，到一把"好尺子"

能区分类 ≠ 能量出冷热。从光秃秃的 θ 走到今天的开尔文，人类还额外规定了三件事、动用了另一条定律。

第一层 · 需要约定

经验温标：四件套缺一不可

① 选测温物质与测温属性 X（水银柱长、铂电阻、热电偶电压……）； ② 选参考点（摄氏：冰点 0、汽点 100）；③ 规定插值规则（通常偷懒假定 X 与温度线性）； ④ 规定单位间隔。

麻烦在于：在两个校准点之外，不同温度计互相不一致——下面可以直接玩。

第二层 · 需要物理条件：理想气体模型

理想气体温标（定容气体温度计）

T = 273.16 K · limptr→0 p / ptr

定容下气体压强随冷热变化；规定水的三相点 = 273.16 K（唯一基准点）； 再取充气压强趋于零的稀薄极限——此时一切气体行为趋于相同，读数与气体种类无关。这是第一个"普适"温标，但它仍依赖"理想气体"这种特殊物质，量程也受气体凝结限制。

第三层 · 需要另一条定律：热力学第二定律

热力学温标（Kelvin, 1848）

卡诺定理（第二定律的推论）：一切工作在两个热源间的可逆热机效率相同，与工质无关： η = 1 − Q2/Q1。开尔文据此定义两温度之比：

T2 / T1 = Q2 / Q1　再以三相点 273.16 K 定单位

它不依赖任何物质，存在真正的零点（T ≥ 0，绝对零度不可达是第三定律）， 并通过 dS = δQ/T 把温度与能量、熵联系起来。2019 年起，国际单位制直接固定玻尔兹曼常数 k = 1.380649×10−23 J/K 来定义开尔文。现代摄氏温度：t/°C = T/K − 273.15。

🌡 经验温标的尴尬：只在定点握手言和

三支温度计都用冰点/汽点校准为 0 和 100，中间一律"假设线性"。拖动滑块，看它们在别处差多少：

冰点 0基准读数 T* →汽点 100
偏差来自各物质真实属性的非线性；温度计越复杂，分歧可能越大——这正是必须走向气体温标与热力学温标的原因。
STEP 07

第零定律：它给了什么，没给什么

✓ 它能推出

  • 热平衡是一个等价关系（传递性是经验核心，自反性为约定，对称性在定义中）
  • 全体平衡态可被划分为互不相交、无一遗漏的等价类（等温类）
  • 存在一个态函数（标量）θ，使 a~b ⟺ θ(a)=θ(b)——"温度"这种物理量在逻辑上可以存在
  • 温度相等是热平衡的充要条件，且该判据对任意系统普遍、自洽

✗ 它不能推出

  • 哪个类更热、哪个更冷（次序要靠热流方向的额外经验）
  • θ 的具体函数形式：f(θ) 有无限多种，它一概无权裁决
  • 零点、单位、等距间隔、"1 度"到底意味着多大变化
  • 绝对零度及其不可达性（那要靠第二、第三定律）
  • 温度与能量的定量关系、温度计读数（需要测温约定 + 第二定律）
FINAL ANSWER · 回到核心问题
温度不是藏在自然里等着被"发现"的一个数，
而是我们替热平衡等价类构造的标签函数。
第零定律发放"出生证"，第二定律才赋予它"刻度尺"。
